# 南林课程表

南京林业大学课程表应用，一套解析逻辑、三个端：

- **网页版**（`web/`）：纯静态页面，书签栏按钮一键从教务系统导入课表
- **Windows EXE 版**（`electron/`）：Electron 桌面端，内置教务窗口 + 注入式抓取
- **安卓 APK 版**（`apk/`）：Kotlin + Jetpack Compose 原生端，后台自动更新课表

特色：自动导入教务系统（强智）课表、三校区作息、教学周自动计算、马卡龙配色 UI（多套主题 + 深色模式）、周视图网格 + 整周实习大卡片、课程备忘录。

## 构建方式

三端的打包、签名、测试步骤见 [交接手册.md](交接手册.md)。
