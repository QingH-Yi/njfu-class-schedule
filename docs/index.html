课表该有的样子

给南林学生做的课表 App，不是通用的日程表。它认识你的教务系统。

打开就自动更新

保存一次账号密码，之后每次打开 App 自动登录教务、把最新课表同步下来；失败也不影响已存的课表。

三校区作息

新庄（本部）、淮安、白马，上课时间各不同。切换校区，节次时间自动对上。

教室直接写在格子上

不用点开也能看到在哪上课；点开详情有完整的老师、周次和学分。

课可以自己记

双击课程写备忘录（格子右上角会出现 📝），作业、考试、要带的东西随手记。

空白格能加课

点一下空白格，手动加一门课：每周 / 单周 / 双周 / 仅本周都行。

顺手的样子

左右滑换周，顶部日期条跟着走；4 套色系、深色模式、反色，怎么顺眼怎么来。
