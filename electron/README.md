# 南林课程表 · EXE 版（Electron）

复用 `web/` 网页版界面，额外提供：
- **内置教务窗口**：点导入时弹出，自动打开教务系统，**右上角固定一个工具条**（自动登录 / 抓取课表），位置不动。
- **一键全自动导入**：设置里存一次学号密码（仅存本机 `userData/config.json`），点一下自动登录并抓取；遇到验证码才需手动输一下，然后点右上角「抓取课表」。

> 说明：EXE 用 Electron（内嵌 Chromium），因为它能真正直连教务系统、绕过网页跨域限制，实现全自动。这跟"网页版不需要装任何东西"是两套东西——网页版依然是纯网页，EXE 是带全自动导入的桌面程序。

## 打包步骤（在有 Node.js 的 Windows 上）
```bat
cd electron
npm install
npm run start     :: 先本地跑起来自测
npm run dist      :: 生成安装包，产物在 electron/dist/（.exe 安装器）
```
- `npm install` 会下载 Electron（约 100MB+），需联网。
- `npm run dist` 用 electron-builder 打出 Windows 安装包（NSIS），可选安装目录、建桌面快捷方式。
- 安装包里已自动包含 `web/`（通过 extraResources），无需手动复制。

## 目录结构
```
electron/
  package.json       依赖 + electron-builder 打包配置
  main.js            主进程：主窗口 + 内置教务窗口 + 自动登录 + 抓取回传
  preload.js         主窗口桥：暴露 window.njfu 给网页版
  jwgl-preload.js    教务窗口桥：抓取按钮的 DOM 事件 -> 主进程
```

## 工作流程
1. 主窗口点「📥 从教务导入」→ EXE 里多出「一键导入」区块，填学号密码 → 点「🚀 一键导入课表」。
2. 弹出内置教务窗口，自动打开教务系统并尝试自动登录。
3. 若出验证码：手动输入登录 → 进入「学生课表查询」选好学期。
4. 点窗口右上角固定的「⬇ 抓取课表」→ 页面 HTML 回传主窗口 → 用 `web/js/parser.js` 解析并保存。

## 关于自动登录
各校正方系统登录实现略有差异（有的带验证码、有的密码加密）。这里用"通用字段识别 + 提交"的尽力而为方式：
- 识别常见用户名/密码输入框并填入、提交。
- 检测到验证码框则不自动提交，提示人工输入。
- 无论是否自动登录成功，「抓取课表」在你手动登录后都能用（这是最稳的一环）。

如需适配南林具体的登录接口/加密，可在 `main.js` 的 `autoLogin()` 里按实际页面结构调整选择器或加密逻辑。
