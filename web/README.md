# 南林课程表 · 网页版

南京林业大学定制版课程表。纯静态网页，无需服务器、无需联网即可用（只有"从教务系统导入"需要联网）。

## 快速开始
直接双击打开 `web/index.html` 即可。
（推荐用 Chrome / Edge。也可以放任意静态服务器或网盘在线打开。）

## 功能
- **课表格子**：周一～周日 × 第1-11节，卡片显示「课程名 + 教室」。
- **点卡片 → 详情**：显示课程名、任课老师、教室、星期、节次(含时间)、完整周次；可编辑/删除。
- **三校区作息**：新庄(本部) / 淮安 / 白马，左列时间自动切换（白马第一节 08:30，其余 08:00）。
- **内置校历**：2026-2027 第一学期，共 20 周，第一周周一 = 2026-08-31。点「📅 校历」查看每周日期。
- **节假日 / 调休**：放假的日子在表头标红、课程置灰；周三第7-8节自动标"集中活动"。
- **当前周**：按第一周周一日期自动计算，也可在设置里手动指定。
- **增删改 + 备份**：本地 localStorage 保存；支持导出/导入 JSON、打印成 PDF。

## 从教务系统导入（书签方式）
1. 打开课程表 → 点「📥 从教务导入」。
2. 首次：把弹窗里的「📎 导入课表到网页」按钮**拖到浏览器书签栏**（`Ctrl+Shift+B` 显示书签栏）。
3. 每次导入：点弹窗里的「打开教务系统」→ 登录 → 进入「学生课表查询」选好学期 → 点书签栏的导入按钮 → 课表自动回传保存。
4. 备选：在教务系统课表页 `Ctrl+U` 查看源码、全选复制，粘贴到弹窗里「解析粘贴内容」。

> 说明：浏览器不允许普通网页跨站抓取教务数据，所以用"书签在教务页面内运行 + 回传"的方式绕开限制，这是纯前端最省事的全自动方案。

## 校历与作息数据来源
`web/js/app.js` 顶部：
- `NJFU_CALENDAR`：学期、第一周周一、总周数、寒假、说明。
- `CAMPUS_TIMES`：三校区作息时间表。
- `DEFAULT_HOLIDAYS`：默认节假日（国庆/中秋/元旦为参考日期，**放假安排以校办通知为准，可在数据里改**）。

## 文件结构
```
web/
  index.html        页面结构 + 弹窗
  css/style.css     样式（含响应式、打印）
  js/parser.js      正方教务课表解析器（处理合并单元格/节次/周次）
  js/importer.js    书签(Bookmarklet)生成器
  js/app.js         主逻辑：存储、渲染、增删改、校历、节假日
```
